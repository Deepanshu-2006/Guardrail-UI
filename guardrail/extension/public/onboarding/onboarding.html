Installing Guardrail for the Controlled Pilot

Developer Mode Unpacked
  1. 1
    Build Extension Assets: npm run build:pilot (or npm run build) in the guardrail/extension directory. This compiles TypeScript to dist/.
  2. 2
    Open Chrome Extensions: In Google Chrome, navigate to chrome://extensions in the address bar.
  3. 3
    Enable Developer Mode: Turn on the Developer mode toggle located in the top-right corner of the Extensions page.
  4. 4
    Load Unpacked Extension: Click the Load unpacked button and select the guardrail/extension/dist directory.
  5. 5
    Pin Guardrail to Toolbar: Click the puzzle-piece Extensions icon in the browser toolbar and pin Guardrail for one-click access to status and diagnostics.
  6. 6
    Verify Background Service Worker: Confirm that the extension card on chrome://extensions displays "Inspect views: service worker" and reports status as active.

What Guardrail UI Protects

Supported pilot test actions
  • Designated pilot test actions marked with data-guardrail-test-action.
  • Synchronous event cancellation of designated transfer and credential actions.
  • Holding intercepted actions in Staging Mode for deliberate confirmation or cancellation.
  • Out-of-band approval requests routed to the Guardrail Trusted-Contact Dashboard.
  • Fail-closed protection when policy configuration is corrupted or uninitialized.
✕

What Guardrail UI Does NOT Protect

Unmonitored web activity
  • Arbitrary, unmarked third-party web pages and unhandled DOM events.
  • Ambient background scripts, asynchronous fetch/XHR, or WebSockets initiated by page JavaScript.
  • Web pages loaded before extension installation or when the service worker is inactive.
  • Phishing websites, malicious browser extensions, keyloggers, or OS malware.
  • Direct browser navigation, browser address bar, downloads, or password managers.

How Staging Mode Works

Synchronous Interception

When you trigger a supported high-risk action (such as a large financial transfer button or credential modification form on a designated pilot page), Guardrail's Staging Mode engages automatically:

1

Synchronous Hold

The action event is cancelled synchronously before browser propagation. It is placed into HELD state in browser memory.

2

Zero Automatic Execution

Crucial Safety Invariant: Guardrail NEVER automatically replays or submits the held action behind your back, even if approved.

3

Deliberate Confirmation

Continuing the action requires your explicit, physical confirmation click in the Staging Mode dialog after authorization is verified.

4

Cancel at Any Time

You can cancel the held action at any moment to safely discard it without modifying web page state.

How Trusted Contacts Participate

Decoupled Human Review

1. Out-of-Band Notification

When an action requires secondary approval, an approval request is dispatched to the backend with high-level metadata (action category, target element descriptor, timestamp). No raw sensitive form values are sent.

2. Independent Dashboard Review

Trusted contacts review pending requests on the standalone Guardrail Dashboard. They can independently approve or reject the action based on predefined safety criteria.

3. Decision Decoupling

A trusted contact's approval only grants authorization. It does NOT execute the action. You retain full control to confirm or cancel the action on your device.
