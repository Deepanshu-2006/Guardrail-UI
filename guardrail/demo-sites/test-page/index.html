Guardrail Test Page

This controlled test page provides standard interactive elements (buttons, links, text inputs, textareas, dropdowns, and forms) to verify the Guardrail Action Detection engine.

Interactive Elements

These controls are explicitly marked with data-guardrail-test-action. Each button maps to a distinct response decision based on existing heuristics:
• ALLOW (Score 0): Routine action. Guardrail does NOT intercept; normal page click handler executes.
• WARN (Score 50): Destructive profile action. Guardrail displays advisory modal; action is NOT held and no interception record is created.
• PROTECT (Score 100): Compound critical action. Guardrail halts event propagation, creates an interception record in HELD, and displays a development message while waiting for a protection decision.
